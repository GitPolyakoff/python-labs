# Веб-приложение интернет-блога

Данный проект разработан в рамках одиннадцатой лабораторной работы по дисциплине «Программирование на языке Python». Это веб-приложение небольшого интернет-блога, созданное на базе фреймворка Django. Приложение предоставляет функционал для добавления новых статей и групп статей, а также поддерживает редактирование и удаление существующих записей. Помимо базовых операций управления контентом, в приложении реализована система фильтрации, позволяющая выполнять поиск по наименованию статей, дате публикации и автору.
